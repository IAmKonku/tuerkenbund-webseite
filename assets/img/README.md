# Bilder

Die Webseite zeigt Platzhalter, bis die passende Datei hier liegt. Sobald eine Datei mit dem richtigen Namen vorhanden ist, erscheint sie automatisch.

| Datei | Wo | Empfohlenes Format |
|---|---|---|
| `logo.png` | Header, Footer, Favicon | PNG mit transparentem Hintergrund, quadratisch, mind. 256×256 px |
| `hero.jpg` | Grosses Bild ganz oben (wird abgedunkelt) | Querformat, ca. 2400×1400 px |
| `gaetsch.jpg` | Kasbahfest «Gätsch» | Querformat oder quadratisch, ca. 1400×1200 px |
| `geschichte.jpg` | Geschichte (historisches Foto) | 4:3, ca. 1200×900 px |
| `ministerium/grossvezier.jpg` | Grossvezier | Hochformat 3:4, ca. 600×800 px |
| `ministerium/goldpascha.jpg` | Goldpascha | Hochformat 3:4 |
| `ministerium/tintenpascha.jpg` | Tintenpascha | Hochformat 3:4 |
| `ministerium/kasbahmufti.jpg` | Kasbahmufti | Hochformat 3:4 |
| `ministerium/scheich.jpg` | Scheich | Hochformat 3:4 |
| `ministerium/sultan.jpg` | Sultan | Hochformat 3:4 |
| `ministerium/kalif.jpg` | Kalif | Hochformat 3:4 |
| `galerie/01.jpg` … `galerie/08.jpg` | Impressionen | `01` gross (Querformat), `03` hoch, Rest beliebig, ca. 1600 px lange Seite |

Tipp: Fotos vorher auf max. ~1600 px (Porträts ~800 px) verkleinern, damit die Seite schnell lädt.
