# tuerkenbund-webseite

Neue Webseite für die Fasnachts-Zunft Türkenbund Brig-Mekka (tuerkenbund.ch).

- `index.html`: die ganze Seite (Onepager, HTML/CSS/JS in einer Datei, ohne Build-Schritt)
- `assets/img/`: Logo und Fotos, Dateinamen siehe [`assets/img/README.md`](assets/img/README.md)

Lokal ansehen: `index.html` im Browser öffnen.

Die Termine stehen direkt im Abschnitt `Agenda` in `index.html`. Die Countdown-Daten stehen im Script unten (`GAETSCH`).
